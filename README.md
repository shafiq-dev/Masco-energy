# MASCO Energy

Corporate homepage explorations for MASCO Energy — nine design directions built with Next.js.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The app redirects to `/main`, a gallery of all nine homepage variants.

## Routes

- `/main` — direction picker
- `/home/classic` — Classic Hero
- `/home/minimal` — Minimal Editorial
- `/home/services` — Services Grid
- `/home/split` — Split Narrative
- `/home/editorial` — Editorial Bands
- `/home/monumental` — Monumental Executive
- `/home/kinetic` — Kinetic Systems
- `/home/dossier` — Institutional Dossier
- `/home/luminous` — Luminous Precision

## Scripts

- `npm run lint` — ESLint
- `npm run build` — production build (Windows-safe timestamped output folder)
- `npm run verify:production` — checks the latest build's assets and profile sections
- `npm run start:local` — serves the latest build at http://localhost:3001/main

See `PRODUCTION.md` for the full production workflow.
